# Mastra AI Framework

This directory contains Mastra agents, tools, and workflows for AI-powered features in the application.

## Structure

- **agents/** - AI agents that process tasks and make decisions
- **tools/** - Reusable tools that agents can invoke
- **workflows/** - Multi-step workflows that orchestrate agents and tools
- **index.ts** - Mastra instance configuration and exports

## Key Files

- **index.ts** - Main Mastra export with registered agents, tools, and workflows
